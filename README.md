# Class 7 Motion & Time — Vercel Ready

A static educational website for Class 7 Science chapter **Motion and Time**.

## Files

- `index.html` — website content
- `style.css` — responsive design and animations
- `script.js` — solved questions, calculator and quiz

## Deploy on Vercel

### GitHub method

1. Create a new GitHub repository, for example `class7-motion-time`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open Vercel and choose **Add New → Project**.
4. Import the GitHub repository.
5. Framework Preset: **Other**.
6. Build Command: leave empty.
7. Output Directory: leave empty.
8. Click **Deploy**.

Vercel will serve `index.html` automatically.

## Important

Do NOT upload the previous Tkinter Python file for this website. This version is a normal static website and is designed specifically for Vercel.
